# 🎲 Jogo de Dados - Desafio 5 Rodadas

Um jogo competitivo de sorte e estratégia onde dois jogadores disputam quem acumula mais pontos em 5 rodadas emocionantes. O sistema conta com sorteio inicial de quem começa, animações de dados girando e placar automático.

---

## 🛠️ Tecnologias Utilizadas

* **Next.js** (Framework)
* **Vercel**

---

## 🎮 Como Funciona o Jogo?

1.  **A Vez de Cada Um:** O jogo alterna entre o Jogador A e o Jogador B. O botão do jogador da vez fica destacado.
2.  **Lógica de Pontuação:** Cada rodada soma os valores de dois dados. O vencedor da rodada acumula os pontos no seu placar geral.
3.  **Sistema de Empate:** Se a soma dos dados for igual, a rodada termina em empate e o sistema sorteia quem inicia a próxima.
4.  **O Grande Vencedor:** Após a 5ª rodada, o jogo exibe uma tela final com o campeão absoluto baseado na pontuação acumulada.
